# YouTube UI Clone

A responsive YouTube homepage UI clone built using HTML and CSS.  
This project was created for practicing modern frontend layout techniques such as Flexbox, Grid, responsive design, and reusable UI components.

---

# Features

- Responsive YouTube-style layout
- Sidebar navigation
- Video cards with thumbnails
- Header with search bar and icons
- Responsive Grid/Flexbox design
- Clean UI structure

---

# Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid

- Flexbox and Grid layouts
